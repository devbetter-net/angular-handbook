# Angular Handbook

A structured learning and knowledge repository for Angular, based on the official [Angular documentation](https://angular.dev).

## Overview

This repository is dedicated to learning, exploring, and documenting Angular concepts, APIs, best practices, and development patterns.

Unlike a real-world project repository, which focuses on building and delivering a working application, this repository focuses on understanding Angular itself — from fundamental concepts to advanced topics.

It serves as a personal knowledge base and technical reference for continuous learning and practical development.

## Objectives

- Consolidate Angular knowledge in a structured and organized way.
- Understand Angular fundamentals, architecture, and core concepts.
- Explore Angular APIs, features, and development patterns.
- Document best practices and common development scenarios.
- Provide practical code examples and reusable references.
- Connect theoretical knowledge with real-world implementation.

## Learning Resources

The primary learning resource is the official Angular documentation:

- [Angular.dev](https://angular.dev)
- [Angular Documentation](https://angular.dev/overview)
- [Angular Tutorials](https://angular.dev/tutorials)
- [Angular API Reference](https://angular.dev/api)

## Learning Approach

Each topic should focus on:

1. **Concept** — Understand what it is and why it exists.
2. **How it works** — Explore the underlying mechanisms.
3. **Usage** — Learn how and when to use it.
4. **Examples** — Implement small, focused examples.
5. **Best practices** — Understand recommended approaches and common pitfalls.
6. **Real-world reference** — Identify how the concept is applied in the practical project.

## Principles

- Prefer official documentation over outdated tutorials.
- Focus on understanding concepts rather than memorizing APIs.
- Use practical examples to validate knowledge.
- Keep notes concise, structured, and easy to reference.
- Document important decisions, trade-offs, and lessons learned.
- Keep learning materials aligned with modern Angular practices.
